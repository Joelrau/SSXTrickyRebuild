SSX TrickyRebuild

The PS2 snowboarding classic, rebuilt from scratch in Unreal Engine 5.8. The riding, tricks, rival racers, menus and music all work just like the original, and you build it yourself from your own copy of the game.

View on GitHub How to build it
No game files here. You'll need your own copy of SSX Tricky (the North American PS2 release, SLUS-20326). The build tools turn it into the PC version on your own computer, so the game, its files and ready-made builds are never available to download.

One game, two looks

Switch between them whenever you like in Options → Video → Look. Everything you play stays the same either way.

Classic

Just like you remember

Rewritten to play exactly like the PS2 original and tested against recordings of the real game. It looks the way it did back then, too.

Enhanced

A fresh coat of paint

Every track gets its own sun, sky and haze, with modern lighting and reflections, properly lit riders, softer snow spray and sharper menus.

PC

Made for PC

Pick your resolution, fullscreen or windowed, graphics quality, VSync, a frame cap and your own keys, with optional AMD FSR upscaling and frame generation.

The Enhanced look

It changes how the game looks and nothing else. Classic is still the default.

  • Each track has its own sun, sky and haze, matched to its original lighting and sky.
  • The original lighting is still there underneath, so every track keeps its familiar colours.
  • Riders are properly lit, cast real shadows and catch the sun on shiny boards and suits.
  • Ice looks icy, powder looks soft, and your board carves grooves into the snow.
  • Lamps glow through the fog at night, water ripples, and night skies are full of stars.
  • Graphics settings from Low to Epic, with ray tracing on Epic if your graphics card supports it.
Only want the original? Run package.bat Classic to get a version without any of the Enhanced extras.

How to build it

A single command builds everything for you. The first build takes a while, so expect it to run for a couple of hours.

  • A Windows 10 or 11 PC with about 40 GB of free space
  • Unreal Engine 5.8 (free from the Epic Games Launcher)
  • Visual Studio 2022 or 2026 with "Game development with C++"
  • Python 3.10 or newer, plus pip install pycdlib pillow numpy capstone zstandard
  • A short folder path, like C:\SSXTrickyRebuild
  • A disc image of your own SSX Tricky (North American release)

  1. Get the code

    git clone https://github.com/Joelrau/SSXTrickyRebuild.git C:\SSXTrickyRebuild

  2. Build from your disc

    Point it at your disc image. It converts the game files, sets up the project and builds a game you can play. 
    build.bat "C:\path\to\your image.iso"

  3. Hit the slopes

    Start Packaged\Windows\SSXTricky.exe. Your build contains files from your disc, so please keep it to yourself.

Want to run the steps one at a time, or something went wrong? The README has the full details and troubleshooting tips.

How it was made

Everything here was written by AI: working out how the original game works, the Unreal code, the conversion tools, the tests and these pages. It's tested against recordings of the real game, but nobody has reviewed the code the way they would with hand-written software.
